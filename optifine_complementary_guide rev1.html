Shader Installation Guide คู่มือติดตั้ง Shader

Complementary & BSL Shaders with OptiFine  ·  Minecraft Java Edition 1.21.x  ·  CrawfordClan MC Server

Complementary และ BSL Shaders พร้อม OptiFine  ·  Minecraft Java Edition 1.21.x  ·  CrawfordClan MC Server

Option A  ·  Complementary Shaders (recommended) ตัวเลือก A  ·  Complementary Shaders (แนะนำ)

1
Download & install OptiFine ดาวน์โหลดและติดตั้ง OptiFine

Before installing, make sure you've launched vanilla Minecraft at least once with no mods. Then grab OptiFine from the official site.

ก่อนติดตั้ง ให้แน่ใจว่าคุณได้เปิด Minecraft แบบ vanilla (ไม่มีม็อด) อย่างน้อยหนึ่งครั้งก่อน จากนั้นดาวน์โหลด OptiFine จากเว็บไซต์ทางการ

Once downloaded, right-click the .jar file → Open with → Java → click Install. A confirmation popup will appear when done.

เมื่อดาวน์โหลดแล้ว คลิกขวาที่ไฟล์ .jar → เปิดด้วย → Java → คลิก Install จะมีหน้าต่างยืนยันปรากฏขึ้นเมื่อเสร็จสิ้น

↓ optifine.net/downloads
💡 After installing, open the Minecraft Launcher. You'll see a new OptiFine profile in your installations list. Select it and hit Play to launch with OptiFine active. หลังติดตั้ง เปิด Minecraft Launcher จะเห็นโปรไฟล์ OptiFine ใหม่ในรายการ ให้เลือกโปรไฟล์นั้นแล้วกด Play
2
Choose your Complementary style เลือกสไตล์ Complementary ของคุณ

Complementary comes in two flavours. For the CrawfordClan MC Server's medieval theme, Unbound is recommended.

Complementary มีสองสไตล์ สำหรับธีมยุคกลางของ CrawfordClan MC Server แนะนำให้ใช้ Unbound

Recommended for CrawfordClan แนะนำสำหรับ CrawfordClan
Unbound
Realistic lighting, volumetric fog, deep shadows. Makes castles and torchlit halls look cinematic. แสงสมจริง หมอกปริมาตร และเงาลึก ทำให้ปราสาทและห้องโถงที่จุดคบเพลิงดูน่าประทับใจ
↗ Download Unbound
Reimagined
Vibrant, closer to vanilla feel. More colourful skies and slightly lighter on performance. สีสันสดใส ใกล้เคียงกับ vanilla มากกว่า ท้องฟ้าสีสันสวยงาม และใช้ทรัพยากรน้อยกว่าเล็กน้อย
↗ Download Reimagined
3
Place the shader pack file วางไฟล์ shader pack

Drop the downloaded .zip file into your shaderpacks folder. Do not unzip it.

นำไฟล์ .zip ที่ดาวน์โหลดมาวางในโฟลเดอร์ shaderpacks ห้ามแตกไฟล์

%AppData%\.minecraft\shaderpacks
📁 Alternatively, launch Minecraft with OptiFine, go to Options → Video Settings → Shaders, and click the Shaders Folder button — it opens the correct folder automatically. หรืออีกวิธีคือ เปิด Minecraft ด้วย OptiFine ไปที่ Options → Video Settings → Shaders แล้วคลิกปุ่ม Shaders Folder ระบบจะเปิดโฟลเดอร์ให้อัตโนมัติ
4
Enable the shader in-game เปิดใช้งาน shader ในเกม

Launch Minecraft using the OptiFine profile. Go to Options → Video Settings → Shaders. Select Complementary from the list and click Done.

เปิด Minecraft ด้วยโปรไฟล์ OptiFine ไปที่ Options → Video Settings → Shaders เลือก Complementary จากรายการ แล้วคลิก Done

The world will reload with shaders active. This may take a few seconds the first time.

โลกจะโหลดใหม่พร้อม shader ที่เปิดใช้งาน อาจใช้เวลาสักครู่ในครั้งแรก

5
Pick a performance profile เลือกโปรไฟล์ประสิทธิภาพ

Inside the Shaders menu, click Shader Options to find the performance profile selector. Start at Medium and adjust from there.

ในเมนู Shaders คลิก Shader Options เพื่อเลือกโปรไฟล์ประสิทธิภาพ เริ่มที่ Medium แล้วปรับตามความเหมาะสม

⚠️ NPC skin note: The CrawfordClan MC Server uses many custom-skinned NPCs — guards, shopkeepers, and more. If NPC faces look incorrect after enabling the shader, open Shader Options → Lighting and turn off Old Lighting. Switching to the Reimagined style instead of Unbound also tends to resolve entity rendering issues. หมายเหตุเกี่ยวกับสกิน NPC: CrawfordClan MC Server มี NPC ที่ใช้สกินแบบกำหนดเองจำนวนมาก ได้แก่ ทหารรักษาการณ์ พ่อค้า และอื่นๆ หากใบหน้า NPC แสดงผลผิดปกติหลังเปิด shader ให้ไปที่ Shader Options → Lighting แล้วปิด Old Lighting การเปลี่ยนไปใช้สไตล์ Reimagined แทน Unbound ก็มักช่วยแก้ปัญหาการแสดงผล entity ได้เช่นกัน

Option B  ·  BSL Shaders (alternative) ตัวเลือก B  ·  BSL Shaders (ทางเลือก)

About BSLเกี่ยวกับ BSL
What makes BSL different BSL แตกต่างจาก Complementary อย่างไร

BSL Shaders is the pack that Complementary was originally built on. It's brighter, more saturated, and punchier — think vivid skies and high-contrast shadows. Great if you want a more dramatic, cinematic look.

BSL Shaders คือ shader pack ที่ Complementary ถูกสร้างขึ้นมาจาก มีความสว่างกว่า สีสันจัดจ้านกว่า และดูโดดเด่นกว่า เหมาะสำหรับผู้ที่ต้องการภาพที่ดูดราม่าและน่าประทับใจ

The install process is identical to Complementary — OptiFine is required, and the .zip goes in the same shaderpacks folder. Players can switch between the two packs without reinstalling anything.

กระบวนการติดตั้งเหมือนกับ Complementary ทุกประการ ต้องใช้ OptiFine และวางไฟล์ .zip ในโฟลเดอร์ shaderpacks เดียวกัน ผู้เล่นสามารถสลับระหว่างทั้งสองได้โดยไม่ต้องติดตั้งใหม่

Step 1
Download BSL Shaders ดาวน์โหลด BSL Shaders

BSL is available on CurseForge and Modrinth. Always download from the official sources below — avoid third-party rehost sites.

BSL มีให้ดาวน์โหลดบน CurseForge และ Modrinth ดาวน์โหลดจากแหล่งทางการเท่านั้น หลีกเลี่ยงเว็บไซต์อื่นที่ไม่ใช่ทางการ

↗ CurseForge ↗ Modrinth
Step 2
Install — same process as Complementary ติดตั้ง — ขั้นตอนเดียวกับ Complementary

OptiFine must already be installed (see Option A, Step 1 above). Drop the BSL .zip into your shaderpacks folder without unzipping it, then select it in-game under Options → Video Settings → Shaders.

ต้องติดตั้ง OptiFine ก่อน (ดูตัวเลือก A ขั้นตอนที่ 1) จากนั้นวางไฟล์ .zip ของ BSL ในโฟลเดอร์ shaderpacks โดยไม่ต้องแตกไฟล์ แล้วเลือกใช้งานในเกมที่ Options → Video Settings → Shaders

🔄 You can have both BSL and Complementary in your shaderpacks folder at the same time and switch between them freely in the Shaders menu. คุณสามารถมีทั้ง BSL และ Complementary ในโฟลเดอร์ shaderpacks พร้อมกันได้ และสลับใช้งานได้อย่างอิสระในเมนู Shaders
Step 3
Pick a BSL performance profile เลือกโปรไฟล์ประสิทธิภาพ BSL

BSL offers four profiles. Access them via Shader Options in the Shaders menu. Start at Medium.

BSL มีสี่โปรไฟล์ เข้าถึงได้ผ่าน Shader Options ในเมนู Shaders เริ่มที่ Medium

LowLow-end PCsPC สเปคต่ำ
MediumStart hereเริ่มที่นี่
HighMid-range+สเปคกลางขึ้นไป
UltraHigh-end onlyสเปคสูงเท่านั้น
⚠️ BSL & NPC skins: BSL generally handles custom-skinned NPCs well, but if you notice face-layer glitches on guards or shopkeepers, go to Shader Options → Post Processing and try toggling off Bloom or reducing Shadow Quality. If problems persist, switch to Complementary Reimagined which has the most reliable entity rendering. BSL และสกิน NPC: โดยทั่วไป BSL รองรับ NPC ที่มีสกินแบบกำหนดเองได้ดี แต่หากพบปัญหาการแสดงผลใบหน้าของทหารหรือพ่อค้า ให้ไปที่ Shader Options → Post Processing แล้วลองปิด Bloom หรือลด Shadow Quality ลง หากยังมีปัญหา ให้เปลี่ยนไปใช้ Complementary Reimagined ซึ่งรองรับการแสดงผล entity ได้ดีที่สุด
