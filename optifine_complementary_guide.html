Shader Installation Guide

Complementary & BSL Shaders with OptiFine  ·  Minecraft Java Edition 1.21.x  ·  For use on this server with custom NPCs

Option A  ·  Complementary Shaders (recommended)

1
Download & install OptiFine

Before installing, make sure you've launched vanilla Minecraft at least once with no mods. Then grab OptiFine from the official site.

Once downloaded, right-click the .jar file → Open with → Java → click Install. A confirmation popup will appear when done.

↓ optifine.net/downloads
💡 After installing, open the Minecraft Launcher. You'll see a new OptiFine profile in your installations list. Select it and hit Play to launch with OptiFine active.
2
Choose your Complementary style

Complementary comes in two flavours. For this server's medieval theme, Unbound is recommended.

Recommended for this server
Unbound
Realistic lighting, volumetric fog, deep shadows. Makes castles and torchlit halls look cinematic.
↗ Download Unbound
Reimagined
Vibrant, closer to vanilla feel. More colourful skies and slightly lighter on performance.
↗ Download Reimagined
3
Place the shader pack file

Drop the downloaded .zip file into your shaderpacks folder. Do not unzip it.

%AppData%\.minecraft\shaderpacks
📁 Alternatively, launch Minecraft with OptiFine, go to Options → Video Settings → Shaders, and click the Shaders Folder button — it opens the correct folder automatically.
4
Enable the shader in-game

Launch Minecraft using the OptiFine profile. Go to Options → Video Settings → Shaders. Select Complementary from the list and click Done.

The world will reload with shaders active. This may take a few seconds the first time.

5
Pick a performance profile

Inside the Shaders menu, click Shader Options to find the performance profile selector. Start at Medium and adjust from there.

⚠️ NPC skin note: This server uses many custom-skinned NPCs — guards, shopkeepers, and more. If NPC faces look incorrect after enabling the shader, open Shader Options → Lighting and turn off Old Lighting. Switching to the Reimagined style instead of Unbound also tends to resolve entity rendering issues.

Option B  ·  BSL Shaders (alternative)

About BSL
What makes BSL different

BSL Shaders is the pack that Complementary was originally built on. It's brighter, more saturated, and punchier — think vivid skies and high-contrast shadows. Great if you want a more dramatic, cinematic look.

The install process is identical to Complementary — OptiFine is required, and the .zip goes in the same shaderpacks folder. Players can switch between the two packs without reinstalling anything.

Step 1
Download BSL Shaders

BSL is available on CurseForge and Modrinth. Always download from the official sources below — avoid third-party rehost sites.

↗ CurseForge ↗ Modrinth
Step 2
Install — same process as Complementary

OptiFine must already be installed (see Option A, Step 1 above). Drop the BSL .zip into your shaderpacks folder without unzipping it, then select it in-game under Options → Video Settings → Shaders.

🔄 You can have both BSL and Complementary in your shaderpacks folder at the same time and switch between them freely in the Shaders menu.
Step 3
Pick a BSL performance profile

BSL offers four profiles. Access them via Shader Options in the Shaders menu. Start at Medium.

⚠️ BSL & NPC skins: BSL generally handles custom-skinned NPCs well, but if you notice face-layer glitches on guards or shopkeepers, go to Shader Options → Post Processing and try toggling off Bloom or reducing Shadow Quality. If problems persist, switch to Complementary Reimagined which has the most reliable entity rendering.
